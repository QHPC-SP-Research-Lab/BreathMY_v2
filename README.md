# Respiratory-Rate-RR-Database

The dataset has been generated by selecting 150 recordings from the [BreathMY database](https://github.com/JTORRECRUZ/BreathMY), thereby extending it. This novel database comprises three distinct repositories of respiratory signals, specifically developed for the rigorous design and evaluation of RR estimation methodologies, covering both noise-free and noise-affected scenarios.

## Constituent Datasets

The dataset includes:

- **DR:** Database of noise-free respiratory signals with controlled RR variability, generated through data augmentation techniques.  
- **DSN:** Database with additive white Gaussian noise (AWGN) at different signal-to-noise ratio (SNR) levels (0, -6, and -20 dB).  
- **DN:** Database with environmental acoustic noise at different SNR levels (0, -6, and -20 dB).

---

## File Format

Each audio file is encoded in `.wav` format and follows the naming convention:


DR_9RR_2023_03_15_4_A.wav



Where:

- **DR** → Identifies the source database (e.g., DR).  
- **9RR** → Ground truth RR of the signal, expressed in breaths per minute (bpm). Here, RR = 9 bpm.  
- **2023_03_15** → Date of creation or processing of the signal (YYYY_MM_DD).  
- **4** → Patient index recorded on that specific date (here, the fourth patient recorded on 2023-03-15).  
- **A** → Alphabetical character used to differentiate files and prevent overwriting when applying data augmentation.  

---

## DR: Database with Noise-Free Respiratory Signals

The **DR** dataset consists of 2,550 respiratory signals, each 60 seconds in duration. It was built using two data augmentation techniques applied to the pre-existing database:

1. **Time Stretching (TS):** Transforms signals with fast RR into signals with slower RR. It preserves the original waveform but increases the duration of each respiratory cycle.  
2. **Cycle Replication (CR):** Transforms signals with slow RR into signals with faster RR. It compresses the duration of each respiratory phase (inhalation and exhalation) and replicates the cycles to complete the recording interval.  

---

## DSN: Database with Additive White Gaussian Noise

To evaluate robustness under controlled noise conditions, the **DSN** dataset is generated from DR by adding AWGN to each signal at three different SNR levels:

- **DSN0 →** SNR = 0 dB  
- **DSN-6 →** SNR = -6 dB  
- **DSN-20 →** SNR = -20 dB  

AWGN uniformly affects all frequency components and represents a standard, demanding scenario for assessing algorithm performance. Each subset preserves the same number of signals as DR, resulting in a total of **7,650 signals** — 2,550 respiratory signals mixed with AWGN for each SNR level.  

---

## DN: Database with Environmental Acoustic Noise

The **DN** dataset simulates real-world environments by adding environmental acoustic noise to each signal from DR at three SNR levels, containing a total of **7,650 signals** — 2,550 respiratory signals mixed with environmental noise for each SNR level:

- **DN0 →** SNR = 0 dB  
- **DN-6 →** SNR = -6 dB  
- **DN-20 →** SNR = -20 dB  

Noises originate from two types of environments:

- **Clinical (Soundsnap):** Medical equipment, conversations, footsteps in corridors, and other typical hospital sounds.  
- **Urban (DCASE):** Ten different acoustic scenes, including streets, public transport, indoor spaces, etc.  

For each mixture:

- The type of noise is assigned randomly.  
- A random 60-second segment of noise is extracted to ensure variability.  
- A balanced representation of all noise types is maintained.  
- Noise segments used for training and testing are mutually exclusive to reduce overfitting.
