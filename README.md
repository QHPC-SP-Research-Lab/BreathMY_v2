## About The Database

The dataset has been generated by selecting 150 recordings from the [BreathMY database](https://github.com/JTORRECRUZ/BreathMY), thereby extending it. This novel database comprises three distinct repositories of respiratory signals, specifically developed for the rigorous design and evaluation of RR estimation methodologies, covering both noise-free and noise-affected scenarios.

The dataset includes:

- **DR:** Database of noise-free respiratory signals with controlled RR variability, generated through data augmentation techniques.  
- **DSN:** Database with additive white Gaussian noise (AWGN) at different signal-to-noise ratio (SNR) levels (0, -6, and -20 dB).  
- **DN:** Database with environmental acoustic noise at different SNR levels (0, -6, and -20 dB).

<a name="file-format"></a>
## File Format

Each audio file is encoded in `.wav` format and follows the naming convention:


DR_9RR_2023_03_15_4_A.wav



Where:

- **DR** → Identifies the source database (e.g., DR).  
- **9RR** → Ground truth RR of the signal, expressed in breaths per minute (bpm). Here, RR = 9 bpm.  
- **2023_03_15** → Date of creation or processing of the signal (YYYY_MM_DD).  
- **4** → Patient index recorded on that specific date.  
- **A** → Alphabetical character used to differentiate files and prevent overwriting when applying data augmentation.

## DR: Database with Noise-Free Respiratory Signals

The **DR** dataset consists of 2,550 respiratory signals, each 60 seconds in duration. It was built using two data augmentation techniques:

1. **Time Stretching (TS):** Transforms signals with fast RR into slower RR, preserving the waveform but increasing cycle duration.  
2. **Cycle Replication (CR):** Transforms signals with slow RR into faster RR, compressing each respiratory phase and replicating cycles to complete the recording.

<a name="dsn-database"></a>
## DSN: Database with Additive White Gaussian Noise

The **DSN** dataset evaluates robustness under controlled noise by adding AWGN to each DR signal at three SNR levels:

- **DSN0 →** SNR = 0 dB  
- **DSN-6 →** SNR = -6 dB  
- **DSN-20 →** SNR = -20 dB  

Each subset preserves the same number of signals as DR, totaling **7,650 signals**.

<a name="dn-database"></a>
## DN: Database with Environmental Acoustic Noise

The **DN** dataset simulates real-world environments by adding environmental acoustic noise to DR signals at three SNR levels:

- **DN0 →** SNR = 0 dB  
- **DN-6 →** SNR = -6 dB  
- **DN-20 →** SNR = -20 dB  

Noise types:

- **Clinical (Soundsnap):** Medical equipment, conversations, footsteps, etc.  
- **Urban (DCASE):** Streets, public transport, indoor spaces, etc.  

Notes:

- Noise type assigned randomly.  
- Random 60-second segment extracted.  
- Balanced representation ensured.  
- Training and testing segments are mutually exclusive.
